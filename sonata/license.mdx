Examples:

- A company's web hosting storefront.
- One organization's game hosting, VPS, app hosting, domain, or private node website.
- A private internal demo for the same licensed owner.

The license does not cover client work, resale, redistribution, marketplace bundling, or selling websites based on Sonata.

## Client Work

Client work is not included in the standard Sonata license.

If a client wants a website built with Sonata, the client must have their own valid license and written permission may be required depending on the arrangement.

Do not use one license to serve multiple clients, companies, brands, or unrelated projects.

## Backups and Private Repositories

You may keep private backups and private repositories for licensed work.

Make sure:

- Repository access is limited to people working on the licensed project.
- Public forks are disabled.
- Build artifacts do not expose private source.
- License markers remain intact.
