## Built for hosting providers

**Sonata** is a premium website theme crafted for game hosting, web hosting, app hosting, VPS, domains, and private node providers. It focuses on polished product pages, tactile UI depth, fast customization, and real hosting workflows.

Designed by **Hiddenmy** and **TariqIsHuman**, Sonata gives hosting brands a complete storefront without forcing developers to start from a blank Next.js project.

<Info>
Whether you are launching a new hosting brand or replacing an older website, Sonata is built to feel premium, responsive, and practical from day one.
</Info>

This documentation covers installation, configuration, customization, product data, integrations, deployment, licensing, FAQ, and troubleshooting.

## What Sonata Includes

- Game hosting pages with plans, stock badges, locations, software options, and billing cycles.
- Web hosting page with pricing cycles, apps, features, stats, and FAQ.
- App hosting, VPS, and private node catalogs.
- Domain pricing and RDAP lookup.
- Status and uptime pages.
- Support and MDX documentation pages.
- Config-driven brand, SEO, billing, and social links.
- Light and dark mode design tokens.
- Tactile button and card depth styling.
- Commercial license and anti-piracy markers.
