## Documentation principles

- Instructions describe released behavior, not planned work.
- Destructive steps include a backup or recovery path.
- Commands identify the directory in which they must run.
- Screenshots support the instructions; they do not replace them.
- Product names and setting labels match the application UI.

<Note>
  Zaqua documentation is maintained alongside active product development. Check each
  product's changelog before upgrading a production installation.
</Note>
