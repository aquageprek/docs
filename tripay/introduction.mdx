# TriPay Paymenter Payment Gateway

**TriPay Gateway** is a payment extension for [Paymenter](https://paymenter.org) that enables automated payment processing through Indonesia's most popular channels — QRIS, Virtual Accounts, E-Wallets, and Retail Outlets.

Developed by [Zaqua Studio](https://zaqua.studio), it features a modern UI powered by Alpine.js with real-time countdowns and a seamless checkout experience.

## 💡 Why TriPay?

- ✅ Official TriPay API integration
- ⚡ Instant invoice status update via webhook
- 🌐 Supports IDR and USD (with configurable exchange rate)
- 🔐 HMAC-SHA256 signature verification for secure callbacks
- 🧪 Sandbox mode for testing without real transactions
