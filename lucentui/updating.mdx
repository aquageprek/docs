---
title: 'Update LucentUI'
description: 'Safely update the LucentUI theme and Editor while preserving configuration.'
icon: 'arrows-rotate'
---

LucentUI 3.0 updates use the same two ZIP files as a fresh installation. There is no
PTB or `.paytheme` update path in this release.

<Warning>
  Back up local Blade, CSS, or JavaScript modifications before replacing the theme.
  Saved Editor settings remain in Paymenter's database, but direct file edits are
  overwritten by the new package.
</Warning>

<Steps>
  <Step title="Read the release notes">
    Check the [LucentUI changelog](/lucentui/changelogs) for compatibility notes and
    changes that may affect custom code or extension overrides.
  </Step>

  <Step title="Export the current design">
    Open LucentUI Editor and select **Export**. Store the resulting JSON file with your
    server backup. This gives you a portable copy of all `lucentui_*` settings.
  </Step>

  <Step title="Back up files">
    ```bash
    cd /var/www/paymenter
    cp -a themes/lucentui themes/lucentui.backup
    cp -a public/lucentui public/lucentui.backup
    ```
  </Step>

  <Step title="Replace theme source and public assets">
    Extract the new theme ZIP over `themes/lucentui`, then republish the bundled assets.

    ```bash
    unzip -o /path/to/LucentUI-3.0.0-theme.zip -d /var/www/paymenter/themes
    mkdir -p /var/www/paymenter/public/lucentui
    cp -a /var/www/paymenter/themes/lucentui/public/lucentui/. \
      /var/www/paymenter/public/lucentui/
    ```
  </Step>

  <Step title="Upload the new Editor package">
    Use **Extensions → Available Extensions → Ready to Install / Upload → Upload
    Extension** and select the new `LucentUIEditor-3.0.0-upload.zip`. Paymenter detects
    the installed copy, replaces the extension files, and runs its update lifecycle.
  </Step>

  <Step title="Clear caches and verify">
    ```bash
    cd /var/www/paymenter
    php artisan optimize:clear
    ```

    Reload the administrator panel and storefront. Confirm the version in
    `themes/lucentui/theme.php`, then test both color modes and critical client routes.
  </Step>
</Steps>

## Roll back

If the update fails, restore both backed-up directories, clear caches, and reload the
site. Import the Editor JSON only if the saved database configuration was deliberately
changed during troubleshooting.

```bash
cd /var/www/paymenter
mv themes/lucentui themes/lucentui.failed
mv themes/lucentui.backup themes/lucentui
mv public/lucentui public/lucentui.failed
mv public/lucentui.backup public/lucentui
php artisan optimize:clear
```

<Note>
  Old hashed asset files are harmless when the active `manifest.json` points to the new
  files. For a tidy deployment, synchronize the public directory from the release rather
  than deleting broad application paths.
</Note>
