LucentUI 3.0 does not use the retired global `banner_enabled` setting. Promotional and
operational messages are blocks, so they can be positioned and enabled independently.

## Promo Bar block

Add **Promo Bar** to the homepage or dashboard builder.

| Field | Purpose |
| --- | --- |
| Message | Localized campaign or maintenance copy |
| Coupon code | Optional code displayed with copy behavior |
| Ends at | Optional `YYYY-MM-DD HH:MM` countdown target |
| Link URL | Destination for the strip |

Leave coupon or end time empty when the campaign does not use them.

## Dashboard announcement

Add or edit **Alerts & Notices** on the Dashboard tab. The announcement field supports
Markdown and can be dismissible.

| Tone | Use for |
| --- | --- |
| Info | Neutral service information |
| Success | Completed work or positive updates |
| Warning | Degraded service or required attention |
| Critical | Active incidents or urgent account action |

The same block can show generated notices for unpaid invoices, expiring services, and
two-factor authentication. Use **Collapse after** to keep a busy dashboard compact.

## Announcement extension

Paymenter's Announcement extension has separate list, detail, and dashboard widget views.
Those records are managed by the extension and should be used for durable news posts.
Use LucentUI blocks for short campaign or account-context messages.
