---
title: 'Frequently asked questions'
description: 'Answers about LucentUI installation, configuration, updates, localization, and compatibility.'
icon: 'circle-question'
---

<AccordionGroup>
  <Accordion title="Does LucentUI modify Paymenter core files?">
    No. The release is limited to `themes/lucentui`, the LucentUIEditor extension, and
    published theme assets. Supported extension views live under the theme's vendor
    override directory.
  </Accordion>

  <Accordion title="Do customers need Node.js to install the theme?">
    No. The release ZIP contains a prebuilt `public/lucentui` bundle. Node.js is needed
    only when a developer changes the source CSS or JavaScript.
  </Accordion>

  <Accordion title="Why are there two ZIP files?">
    Paymenter uploads extensions but themes are installed in the `themes` directory. The
    Editor ZIP is structured for **Upload Extension**; the theme ZIP contains the
    `lucentui` theme root and its prebuilt assets.
  </Accordion>

  <Accordion title="Can the theme be completely flat?">
    Yes. Select **Colors → Appearance Mode → Flat UI**, then choose Bordered, Filled, or
    Quiet surfaces. The same content and layout remain in use.
  </Accordion>

  <Accordion title="Can visitors choose light or dark mode?">
    Yes. Set Default Theme to Auto, Light, or Dark and leave Force Theme at **Let users
    choose**. Forcing a mode hides the visitor toggle.
  </Accordion>

  <Accordion title="What happens if I upload only one wallpaper?">
    LucentUI uses it as the fallback for both light and dark mode. A mode-specific upload
    overrides a URL for the same mode.
  </Accordion>

  <Accordion title="How many languages are supported?">
    The Editor follows Paymenter's Allowed Languages list. English is always included as
    the source/fallback; there is no fixed four-language limit.
  </Accordion>

  <Accordion title="Will an update erase my Editor settings?">
    File replacement does not intentionally remove settings because they live in
    Paymenter's database. Export settings and back up files before every update anyway.
  </Accordion>

  <Accordion title="Can I use an extension without a dedicated LucentUI page?">
    Usually. Generic Paymenter components inherit the theme where possible. Extension
    markup with custom fixed styling may look different until a dedicated override is
    added.
  </Accordion>

  <Accordion title="Does LucentUI support Proxmox and BetterPterodactyl?">
    The 3.0 release includes theme-side views for Proxmox and the Pterodactyl SSO service
    surface used by BetterPterodactyl. The extensions remain responsible for server-side
    provisioning and API behavior.
  </Accordion>

  <Accordion title="Can I use Advanced Renewal?">
    LucentUI does not currently ship its planned Advanced Renewal adapter. Customers must
    hold their own valid extension license; paid extension templates are not redistributed
    with LucentUI.
  </Accordion>

  <Accordion title="How do I report a bug?">
    Follow the [troubleshooting checklist](/lucentui/troubleshoot), remove sensitive data,
    then contact the [Zaqua community](https://discord.gg/UYMrM8kDne) with versions,
    reproduction steps, logs, and console output.
  </Accordion>
</AccordionGroup>
