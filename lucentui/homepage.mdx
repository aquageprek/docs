The **Homepage** tab uses a block builder rather than a fixed list of section toggles.
Each block has a stable ID, enabled state, variant, width, and content payload.

## Builder actions

- Drag blocks to change their order.
- Expand a block to edit its content and variant.
- Disable a block without deleting its configuration.
- Clone a block to reuse a type with different content.
- Choose full or half width where the block supports dashboard-style composition.
- Switch the global content language to edit localized block fields.

Switching variants preserves the shared content schema. A cloned block receives a new
stable identifier when saved.

## Product and data-backed blocks

Categories and pricing use live Paymenter data. Stats are supplied through cached theme
data rather than queries inside Blade views. If a referenced category slug or product
name changes, update the corresponding block configuration.

## Legacy upgrades

On an upgraded installation, LucentUI Editor seeds a block list from compatible legacy
settings. After the first successful save, the block list becomes the canonical layout.
Do not hand-edit `homepage_blocks` JSON unless you are restoring a reviewed export.

<Tip>
  Build the narrative in this order: one Hero, proof or Features, Products/Pricing,
  objections such as FAQ, and one final CTA. More sections do not automatically improve
  conversion or clarity.
</Tip>
