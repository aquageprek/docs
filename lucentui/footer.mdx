Open **LucentUI Editor → Navigation & Footer**.

## Footer content

| Setting | Purpose |
| --- | --- |
| Footer Description | Short company description; supports Markdown |
| Copyright Text | Custom copyright, or leave empty for the generated year and app name |
| Hide Paymenter badge | Removes the Paymenter attribution silhouette |
| Privacy Policy URL | Internal or external privacy policy |
| Terms of Service URL | Internal or external terms page |
| Support URL | Ticket, contact, or help center destination |
| External Control Panel URL | Pterodactyl or another service-management panel |

Relative URLs such as `/tickets` stay on the Paymenter domain. Use complete `https://`
URLs for external destinations.

## Social profiles

LucentUI supports Discord, GitHub, Twitter/X, Instagram, YouTube, and TikTok. Empty fields
are omitted rather than rendering inactive icons.

## Recommended production setup

- Keep the footer description to one or two short sentences.
- Link privacy and terms pages before accepting customer payments.
- Point support to the channel your team actually monitors.
- Verify every social URL in a signed-out browser.
- Use custom HTML only when a normal footer field cannot represent the required content.

<Info>
  Footer links, theme navigation, and extension navigation are independent. Changing an
  external control-panel URL does not change server-extension SSO behavior.
</Info>
