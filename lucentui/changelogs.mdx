## Version 3.0.0 — Next-Gen theme and Editor

Released September 2026.

### Theme system

- Added Lucent and fully opaque Flat appearance modes using one shared component tree.
- Added Balanced, Full Glass, Solid, and Minimal Lucent surface hierarchy.
- Added Bordered, Filled, and Quiet Flat surface styles.
- Rebuilt semantic light/dark color tokens and introduced ten coordinated palette presets.
- Reduced surface shadows and visual noise in both color modes.
- Added separate light/dark wallpapers with one-image fallback, shared opacity, and blur.
- Added configurable typography, navbar shapes/alignment, sidebar shapes, and icon rail.

### Page builders and content

- Replaced fixed homepage sections with ordered, cloneable, variant-aware blocks.
- Added the same builder architecture to the authenticated dashboard.
- Added four dashboard starting presets: Default, Minimal, Support-first, and Billing-first.
- Added stable block IDs so reorder and no-op saves preserve configuration.
- Added dynamic localization based on Paymenter's Allowed Languages, with English source
  fallback and preservation of disabled-language translations.
- Added complete localized auth copy, logout confirmation, and polished password/2FA/email
  verification states.

### Commerce and services

- Added six synchronized product card variants and restored parsed product specifications
  to every variant.
- Added `!key=value` product spec shortcodes, pricing metadata filtering, and semantic icons.
- Added scoped icon mappings to prevent numeric ID collisions between game-server and
  Proxmox configuration fields.
- Reworked Proxmox checkout grouping and service views, including telemetry visualization,
  copy feedback, and lifecycle-safe tab behavior.
- Improved compatibility styling for generic extension buttons and actions.

### Extension views

- Added or rebuilt themed views for Announcements, Affiliates, Compliance Tools, Uptime,
  BetterPterodactyl/Pterodactyl SSO, Proxmox, Stripe, and Passport.
- Kept integration changes inside the theme; no Paymenter core patch is required.

### Operations and packaging

- Added live Editor preview for desktop, tablet, mobile, homepage, dashboard, and active locale.
- Added import/export and destructive reset confirmation.
- Added SEO, analytics, navigation, footer, custom code, and invoice PDF controls.
- Added browser release inspection through `LucentUI.inspect()` without exposing the raw nonce.
- Added separate install-ready theme and Paymenter upload ZIP packages with prebuilt assets,
  SHA-256 checksums, and automated archive validation.
