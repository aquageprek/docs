LucentUI 3.0 is a configurable storefront and client-area theme for Paymenter 1.5.8.
It combines a complete theme override with LucentUI Editor, an administrator extension
for changing the visual system and page layouts without editing Paymenter core files.

## Package model

LucentUI is delivered as one downloadable bundle. Extract the bundle on your computer
to get the two install-ready packages:

| Package | Purpose | Installation path |
| --- | --- | --- |
| `LucentUI-3.0.0-bundle.zip` | Single download containing both packages, installation guide, and checksums | Extract locally; do not upload it to Paymenter |
| `LucentUI-3.0.0-theme.zip` | Theme source and prebuilt browser assets | Extract under `themes/lucentui` |
| `LucentUIEditor-3.0.0-upload.zip` | Paymenter administrator extension | Upload from **Available Extensions** |

The two inner ZIP files remain separate because Paymenter can upload the Editor extension,
while themes are placed in the `themes` directory and publish assets to `public`.

<Warning>
  Do not upload the theme ZIP through Paymenter's extension uploader. Do not extract the
  Editor upload ZIP before selecting it in the administrator panel.
</Warning>

The theme package itself contains the compiled frontend bundle and every required local
interface asset: locale flags, service icons, LucentUI Editor artwork, and card-style
previews. There is no separate assets archive to install.

## Design and compatibility guarantees

- No LucentUI installation step requires editing Paymenter core files.
- Normal installations use bundled CSS, JavaScript, flags, service icons, and Editor
  previews and do not require Node.js or an external image host.
- Theme settings are stored in Paymenter's database and survive file-only upgrades.
- Missing optional media collapses or falls back without breaking the page structure.
- Light and dark colors use one semantic token system throughout supported views.
- Extension overrides are isolated inside `themes/lucentui/views/vendor`.
