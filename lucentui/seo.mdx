Open **LucentUI Editor → SEO**. The configured defaults apply to pages that do not provide
more specific metadata.

## Meta tags

| Field | Guidance |
| --- | --- |
| Default Page Title | Brand or storefront name used before page-specific titles |
| Meta Description | Clear page summary; approximately 150–160 characters is a useful target |
| Meta Keywords | Optional comma-separated legacy metadata |
| Author / Company | Company name used in author metadata |
| Robots | Choose index/follow behavior for the storefront |
| Canonical URL Base | Complete production origin such as `https://billing.example.com` |
| SEO / Browser Color | Browser chrome and theme-color accent |

LucentUI appends the current request path to the canonical base. Leave the field empty to
use Paymenter's configured application URL.

## Social sharing

Upload a 1200×630 JPEG, PNG, or WebP Open Graph image. Product/page media can supply a
fallback when no global image is configured. Choose a Summary or Summary Large Image card
and optionally add the Twitter/X account handle.

<Warning>
  Set the canonical base to the public HTTPS hostname. A staging or localhost canonical
  URL can cause search engines to associate production pages with the wrong origin.
</Warning>

## Robots policy

| Value | Meaning |
| --- | --- |
| `index,follow` | Index the page and follow links |
| `index,nofollow` | Index the page but do not follow links |
| `noindex,follow` | Do not index the page; links may be followed |
| `noindex,nofollow` | Do not index or follow links |

Use `noindex,nofollow` on non-production environments. Robots metadata does not replace
authentication for private pages.

## Analytics IDs

LucentUI can inject Google Analytics 4 (`G-...`), Google Tag Manager (`GTM-...`), and
Meta/Facebook Pixel IDs. Leave a field empty to disable that integration.

Before enabling analytics, update the cookie/privacy disclosure for the jurisdictions in
which you operate. Avoid configuring the same tracker through both the built-in field and
custom code, which would duplicate events.

## Validate output

Use browser page source—not only the inspector DOM—to check title, description, canonical,
robots, Open Graph, and Twitter tags. Test a shared URL with the target platform's preview
debugger after deployment.
